# Sablate — releases

Download the latest Sablate build from the [Releases](../../releases) page.

This repository exists to host release artifacts and to serve the update feed
that the app's auto-updater reads. There is no source code here — Sablate is
developed in a private repository.

## Downloads

| File | What it is |
|---|---|
| `Sablate-Setup-<version>.exe` | Windows installer (recommended) |
| `Sablate-Portable-<version>.exe` | Windows, no installation |

Windows builds are signed. The certificate is new, so SmartScreen may still show
an "unknown publisher" warning until it accumulates reputation — that clears with
download volume, not with anything the app can change.

macOS builds are not published yet.
